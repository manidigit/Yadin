## ۲. منطق و الگوریتم‌ها (همه حل شدند)

### ۲.۱ نوع مرور در تاریخچه (ReviewHistory)
- **مشکل قبلی:** همیشه FLASHCARD ثبت می‌شد.
- **تصمیم نهایی:**  
  هم نوع آزمون (FLASHCARD یا QUIZ) و هم نوع مرور (DAILY / WEEKLY / MONTHLY / RANDOM) با هم ثبت شود.
- وضعیت: ✅ حل شد

### ۲.۲ رگبار (Streak)
- **تصمیم نهایی:**  
  با فقط **یک تمرین** (فلش‌کارت یا کوئیز فرقی ندارد) رگبار آن روز افزایش یابد.
- وضعیت: ✅ حل شد

### ۲.۳ جهت آزمون (معمولی / برعکس)
- **تصمیم نهایی:**  
  - جای سؤال و جواب عوض شود.  
  - دکمه صدا **فقط برای سؤال** باشد (حتی در فلش‌کارت).
- وضعیت: ✅ حل شد

### ۲.۴ کلمات غیرفعال (soft-delete)
- **تصمیم نهایی:**  
  - در کتابخانه نشان داده شوند (با علامت غیرفعال).  
  - در آمار شمرده نشوند.  
  - گزینهٔ فعال‌کردن مجدد داشته باشند.
- وضعیت: ✅ حل شد

### ۲.۵ چند ترجمه برای یک کلمه
- **تصمیم نهایی:**  
  در فلش‌کارت **همه ترجمه‌ها** نمایش داده شوند.
- وضعیت: ✅ حل شد

### ۲.۶ تغییر جفت زبانی در تنظیمات
- **تصمیم نهایی:**  
  هیچ اتفاقی برای کلمات قبلی نمی‌افتد. فقط مدل آزمون (جهت سؤال/جواب) عوض می‌شود.
- وضعیت: ✅ حل شد

## ۴. موارد فنی (همه حل شدند)

### ۴.۱ مهاجرت دیتابیس
- **تصمیم نهایی:**  
  نسخه قبلی واقعی وجود دارد (دیتابیس بعداً داده می‌شود). مهاجرت واقعی لازم است.
- وضعیت: ✅ حل شد

### ۴.۲ نرمال‌سازی متن (canonicalKey)
- **تصمیم نهایی (از روی گیت‌هاب و اسناد پروژه):**  
  1. Trim (حذف فاصله اول و آخر)  
  2. تبدیل به حروف کوچک (lowercase)  
  3. تبدیل فاصله‌های پشت‌سرهم به یک فاصله  
  4. **حفظ لهجه و علائم** (مثلاً `sí` و `si` دو مقدار متفاوت هستند)  
  لهجه‌ها و نقطه‌گذاری پاک نمی‌شوند.
- وضعیت: ✅ حل شد

## خلاصه تصمیمات نهایی (قابل استفاده در کد)

| موضوع | تصمیم |
|-------|--------|
| ReviewHistory | هم reviewType (FLASHCARD/QUIZ) و هم نوع مرور (DAILY/WEEKLY/...) ثبت شود |
| Streak | با فقط ۱ تمرین (هر نوعی) افزایش یابد |
| جهت برعکس | جای سؤال/جواب عوض + صدا فقط روی سؤال |
| Soft-delete | در کتابخانه با علامت نشان داده شود، در آمار نه، قابلیت فعال‌سازی مجدد |
| ترجمه‌های متعدد | همه در فلش‌کارت نشان داده شوند |
| تغییر جفت زبانی | فقط جهت آزمون عوض شود، کلمات دست نخورند |
| TTS | در کوئیز، فلش‌کارت و کتابخانه – زبان = زبان سؤال |
| Achievements | داشته باشیم و در صفحه پیشرفت نشان دهیم |
| Backup | بدون رمز + نوار پیشرفت + پیام «با موفقیت انجام شد» |
| i18n | همه متن‌ها دو زبانه + فایل جدا |
| Migration | دیتابیس واقعی قبلی وجود دارد |
| canonicalKey | trim + lowercase + collapse spaces + حفظ لهجه و علائم |
