# GPT Glossy SVG icon set

54 independent SVG icons for the Yadin GPT Glossy visual family.

- SVG viewBox 24×24; intrinsic dimensions 96×96; transparent background.
- Consistent cyan/blue/violet gradient, highlight strokes, rounded joins and soft shadow.
- No external fonts, raster assets or network dependencies.
- Scoped to GPT Glossy; Gemini icons remain untouched.

Android integration is not included in this assets-only commit. Convert SVGs to VectorDrawable or render them through an approved SVG library before using them in Compose.
